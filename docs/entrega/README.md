Lo que hace falta para pasar de la versión del piloto (0.9.0) a la entregada (1.0.0).

| Documento | Para quién | Qué responde |
|---|---|---|
| [`alcance-v1.md`](alcance-v1.md) | TEINS y Kevin | Qué incluye la versión 1, qué queda por fuera y qué depende de información de TEINS |
| [`pendientes-de-teins.md`](pendientes-de-teins.md) | TEINS | Las preguntas y el material que faltan, y qué pasa si no llegan |

Los pasos técnicos para encender producción el día del piloto están en [`../proceso/produccion.md`](../proceso/produccion.md), «Encender producción para el piloto». Los PDF de los manuales se adjuntan a cada versión, en la pestaña **Releases**.

Lo que queda para después de aceptar el piloto, y no está en esta carpeta: la dirección web definitiva, las cuentas a nombre de TEINS (Railway, Geoapify, el correo de salida), el acta de entrega con el cambio de propiedad del código, y la garantía y el soporte.
